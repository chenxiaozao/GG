# 小造智械机器人垂直电商平台

这是以选购体验为中心的课程/毕业设计演示系统，采用 Vue 3、TypeScript、Spring Boot、JPA。当前工程持续升级，原目录和包版本号仍保留 V1.0 名称，不代表已冻结的软著材料也应随源码改变。所有支付、库存展示、物流及估价均为模拟，不接收真实资金。

## 小组本地运行

### 当前选购流程

- 详情、对比、收藏可以带最多4款候选进入AI顾问；发送前可编辑需求，后端重新验证候选与规则。
- 我的空间 → 选购计划：保存需求、预算上限、场景、候选与私人备注，支持最多3份计划比较。
- 计划保存后记录最近20个版本，可载入旧版编辑再保存；删除计划会一并删除版本。
- 收藏支持每件商品的私人备注，不自动发给模型。所有计划/备注接口按账号校验。
- 代码更新后须重启后端以创建新增表/字段；只刷新前端不会更新后端接口。没有后端时这些写入不会伪装成功。

### 启动

准备 Java 17 或 21、Maven 3.9+、Node.js 22。

在 server 文件夹运行：

```sh
mvn spring-boot:run
```

在 web 文件夹另开终端运行：

```sh
npm ci
npm run dev
```

访问 http://localhost:5173 。默认本地模式初始化 user/123456 和 admin/admin123，只用于个人开发，不能直接暴露公网。每位组员使用自己的本地数据库；下载代码不会下载其他人的账号、订单或密钥。

## 使用自己的电脑按需开后端

在 server 运行 `bash run-on-demand.sh`。首次设置管理员密码，数据独立保存在 server/data/on-demand；停止后保留账号和头像。只监听本机，禁用默认演示账号。AI 密钥仅通过后端环境变量设置，不提交到仓库。

如需外网访问，还要配置受控的 HTTPS 隧道或云服务器，详见 [部署与安全说明](server/DEPLOYMENT.md)。当前没有自动启动隧道或购买服务器。

## 在线与离线页面

云端分离部署统一入口：[后端部署手册](server/deploy/README.md)。前端和商品静态图片留在 GitHub Pages；云端只运行 HTTPS 网关、Java、MySQL，持久保存业务数据与头像。运行 `node server/deploy/package.mjs` 生成后端专用包，不会带入本机数据库和密钥。此为本地准备，不代表已购买云资源或完成上线，亦不自动 push。

- 后端正常：注册登录、账号隔离的收藏/购物车/地址、模拟订单/评价/售后、管理端、参数对比、适配、估价、规则推荐及 DeepSeek 对话。
- 后端断开：商品列表、搜索筛选、详情与同类参数对比可使用公开目录快照；明确提示日期和非实时状态。不能伪登录、伪保存、下单或使用 AI。
- 快照仅来自隔离初始化目录，不含用户、订单、地址、头像或密钥；不是实时库存。

GitHub Pages 工作流为手动触发。仓库变量 API_BASE_URL 留空时发布只读版；配置真实 HTTPS 后端地址（以 /api 结尾）后发布完整版。发布设置选择 GitHub Actions，路径为 /GG/，使用 hash 路由。前后端部署与访问可用性仍需实际环境验证。

## 推荐规则

AI只用于机器人及配件选购与商城使用；无关数学作业等先本地拒答，不消耗AI额度。有效问题会发送至DeepSeek，常见手机号/邮箱会过滤，但不保证全面脱敏，请勿输入隐私。

我的空间新增“选购偏好”：默认不收集，开启后只保存明确的结构化选购需求，用户可纠正/删除，管理员可见需另行授权。管理端维护普通账号需再次验证管理员密码，重置后强制改密并撤销旧登录；手机号是未验证联系方式，不是短信绑定。管理操作留审计，不留密码原文。

表单和对话共用类别、预算、库存、必要功能参数及最低续航校验；默认不放宽预算。不把演示评分或销量包装成性能证据。对话中的未知硬性要求会请求澄清，不假定商品具备。支持的功能词和限制见 [推荐验证说明](server/RECOMMENDATION.md)。

模型只负责解释与对话，推荐卡片受规则约束；模型正文不保证无误。AI 配额保存在数据库，按 UTC 自然日重置，重启不清零。失败尝试也计数。

## 检查与测试

```sh
# server
mvn test
mvn -DskipTests package
node deployment-smoke.mjs

# web
npm run build
npx vue-tsc --noEmit
```

部署冒烟检查仅启动临时数据库与本机18080端口，验证数据/头像重启保存、退出和改密撤销、额度持久化、CORS及关闭数据库控制台，不调用真实AI。运行前确保18080未被占用。

浏览器审查脚本在 web/scripts，需先启动本地前端及安装 Chrome；site-completion-audit、service-ui-audit、offline-audit 使用模拟/阻断接口，不是实际公网验收。旧 audit:ai-live 会发送真实模型请求，仅显式选择时运行，并需提供 AUDIT_TOKEN 环境变量。

自动检查流程在 .github/workflows/ci.yml，包含后端测试和前端类型/构建；它只有上传后才会在 GitHub 运行，不能把本地文件当作已运行的 CI。
