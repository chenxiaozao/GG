# 小造智械机器人垂直电商平台

## GitHub 小组协作与线上部署（2026-11-05）

仓库只共享前端 `web`、后端 `server` 和必要配置，不包含本地数据库、密钥、头像、论文和申报材料。下载代码不等于共享同一个数据库；多人共用账号体系需要统一部署后端。

组员启动：在 `server` 中运行 `mvn spring-boot:run`，另一个终端在 `web` 中运行 `npm ci` 和 `npm run dev`。下文的一键脚本、docs 和验收命令属于原本地工程附件，不包含在此精简仓库。现行部署、安全边界、Pages 设置及持久化说明请看 [部署说明](server/DEPLOYMENT.md)。默认演示账号只用于本地，线上必须启用 prod 配置。网站交易均为模拟。

当前目录是持续升级的 V2.0 工作代码，沿用原来的目录名；并非已经冻结的最终交付版。已申报 V1.0 的说明书、程序鉴别材料和申请表保持原样，不应使用升级后的源代码重新覆盖旧材料。系统采用 Vue 3 + TypeScript + Spring Boot 3 + Spring Data JPA + H2，提供机器人及配件选购、模拟交易、评价、售后演示和后台运营。

## 环境

- Java 17 或 21
- Maven 3.9+
- Node.js 20+
- npm 10+

## 一键启动（macOS）

```bash
chmod +x start-all.command verify-v1.command
./start-all.command
```

浏览器访问 `http://localhost:5173`。

## 演示账号

- 普通用户：`user / 123456`
- 管理员：`admin / admin123`

普通用户登录后进入商城首页；管理员登录后进入 `/admin` 商城运营中心。

## 初始化数据

首次启动及后续启动均采用幂等初始化：

- 2 个演示账号
- 10 个分类
- 22 个品牌
- 56 款机器人，覆盖地面清洁、擦窗、庭院与泳池、陪伴娱乐、航拍、教育及专业机器人
- 16 款配件，并建立主机与耗材/电池的适配关系
- 初始目录内的主机/配件演示适配关系（不是官方兼容认证）

启动会补齐缺失的初始商品，并对已知旧目录图片/来源做明确迁移；不再用初始商品数据覆盖管理员编辑，也不会重新上架已下架商品。已有价格、参数、图片、来源、库存、上架状态及订单/用户数据保留。将来更新目录参数须另做可核对的数据迁移，不能默默覆盖后台维护值。

## 自动 API 验收

后端启动后运行：

```bash
./verify-v1.command
```

脚本会核验登录、商品数量、详情、参数对比、购物车、下单、支付、发货、收货、购买后评价、管理员商品新增/编辑/下架及工作台。

## 核心功能

- 商品首页、检索、分类、品牌和价格筛选
- 商品详情、SKU、收藏和浏览历史
- 参数对比、结构化配件适配、可解释选购顾问、DeepSeek AI 对话顾问、旧机估价
- 购物车、订单创建、模拟支付、取消、发货、收货和购买后评价
- 退款、退货、维修售后申请，寄回物流和进度跟踪
- 管理员工作台、商品管理、用户启停、订单发货、售后处理和运营分析
- 个人资料、头像裁剪、地址簿、按账号分隔的收藏/购物车/浏览记录及游客登录合并
- 三种独立布局（经典商城/生活展厅/高效选购），三套预设配色与自定义主题色/背景色

## 界面与素材复测

前端目录可运行 `npm run audit:catalog-media`（型号图、详情来源、错误降级及部分文字对比度）、`npm run audit:theme-contrast`（配色算法抽样）、`npm run audit:responsive`（全站渲染/溢出/固定导航）、`npm run audit:layouts`（独立布局/配色）。`audit:service-ui` 使用隔离接口验证操作，不写入已有用户订单，不能冒充原数据库业务验收。报告位于项目 `tmp/`；已完成/未完成见 [`docs/V2.0_开发进度与续作清单.md`](docs/V2.0_开发进度与续作清单.md)。

## DeepSeek AI 顾问配置

Token 只由后端读取，不得写入前端或提交到代码中。首次使用时双击项目根目录中的 `配置DeepSeek.command`，在终端中粘贴 Token 并回车。配置会保存至已忽略的本机私密文件 `.env.local`，以后只需双击 `start-all.command`。

也可仅为当前终端临时设置：

```bash
export DEEPSEEK_API_KEY="你的 Token"
./start-all.command
```

可选环境变量：`DEEPSEEK_BASE_URL` 和 `DEEPSEEK_MODEL`。未配置 Token 时，规则型选购顾问仍可正常使用，AI 对话区会明确显示“待配置 Token”。
